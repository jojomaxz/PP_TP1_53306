# PP_TP1_53306

El sistema permite:

- Registrar estudiantes.
- Crear eventos universitarios.
- Asignar una sala a cada evento.
- Crear actividades para los eventos.
- Crear actividades de tipo Charla y Taller.
- Inscribir estudiantes en las actividades.
- Calcular el costo estimado de cada evento.
- Mostrar las actividades e inscripciones.
- Contabilizar la cantidad total de eventos creados.

## Requisitos

- Java JDK.
- IntelliJ IDEA o cualquier IDE compatible con Java.
- Git, en caso de querer clonar el repositorio desde consola.


El programa se ejecuta desde la clase: `App.java` La aplicación funciona mediante consola y permite ingresar los datos necesarios para crear estudiantes, eventos, actividades e inscripciones.
